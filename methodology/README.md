# Methodology knowledge base

One file per documented equity researcher whose technique the system encodes. These are loaded
into the relevant agent's prompt (see `src/agents/base.py::methodology_files`). The synthesis of
their *convergent* principles is the House View in `../CLAUDE.md`; their *distinctive* techniques
are bolted onto specific funnel stages here.

**All performance figures are self-reported / unverified unless explicitly noted.** Nothing here
is investment advice.
