# Citrini Research

*Closest to the user's MU (memory-shortage) style: ride a narrative via the right beneficiaries.*

## Core edge
Translate an accelerating **secular narrative** into an investable **basket of beneficiaries**,
deliberately hunting **second-order** effects (the suppliers/enablers/picks-and-shovels) rather
than only the obvious first-order name.

## Distinctive techniques (encode these)
- **Narrative → basket.** Identify the theme, then enumerate the chain of who benefits: first-
  order (the obvious play), second-order (suppliers, enablers, infra), third-order (downstream).
  MU was a second-order AI/datacenter memory play before it was consensus.
- **Hunt second-order beneficiaries.** The first-order name is usually crowded/expensive; the
  asymmetric money is one link up or down the value chain.
- **Catch the trend while it's accelerating, before consensus.** Use news/filings/transcripts
  (Bigdata.com) to detect acceleration early.
- **Factor-neutralize** to isolate selection alpha — make sure the bet is the *theme*, not just
  beta/size/momentum exposure.

## How agents use it
- **Thematic / second-order scout** is built directly on this: detect accelerating themes from
  Bigdata.com, then map the first- and second-order beneficiary chain and surface the
  under-priced link. This is the system's MU engine.
- **Themes & Outlook** dashboard view is a Citrini-style theme tracker (1st/2nd-order map).
